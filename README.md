# Personal website

Buat website portfolio profesional untuk 3D Artist dan 3D Visualizer.

Tujuan: membangun website portfolio interaktif dengan sistem navigasi dan project showcase berbasis slideshow. Gunakan desain visual original, jangan meniru tampilan website referensi secara langsung.

Fitur utama:

Opening page dengan hero image/video fullscreen, nama, profesi, deskripsi, dan tombol navigasi.

Navigasi kategori: Work, Technical Art, Personal Projects, About, Contact.

Sistem slideshow project dengan tombol next/previous, indikator nomor project, dan transisi halus.

Setiap project memiliki halaman detail berisi galeri gambar, judul, deskripsi, software, dan informasi project.

Navigasi keyboard dan swipe pada perangkat mobile.

Responsive untuk desktop, tablet, dan mobile.

Struktur konten mudah diperbarui untuk menambahkan project baru.

Optimasi gambar dan loading agar website tetap cepat.

Gunakan React dan TypeScript. Buat komponen yang reusable dan struktur data project yang mudah dikelola. Gunakan placeholder untuk gambar dan informasi project yang nantinya akan diganti dengan konten asli.
